# Model Card: PARALLAX AIHFT Research

## Release

`parallax-aihft-research-v1.0.0`

## Role

Coordinates research/backtest strategy packages, sandbox wallet boundaries, receipts, and release-readiness evidence for the NOVA/PARALLAX ecosystem.

## Inputs

- strategy definitions
- backtest or system-test receipts
- sandbox ledger records
- operator approvals
- risk boundaries

## Outputs

- research release manifests
- strategy package evidence
- boundary reports
- promotion evidence for NOVA main

## Task capability

- Package strategy research evidence.
- Validate research-only boundaries.
- Preserve wallet/trading approval gates.
- Feed strategy readiness into NOVA.

## Non-capabilities

- Does not execute live trades.
- Does not provide investment advice.
- Does not guarantee returns.
- Does not deploy capital.

## Evaluation

The release harness validates artifact presence, schema alignment, banned financial claims, and explicit operator approval gates.
