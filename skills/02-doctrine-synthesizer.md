### Quality Gates

- **Coherence:** Synthesized doctrine must not contradict existing Laws or Absolutes
- **Depth:** Formalization must go beyond restating the input in fancier language
- **Substance:** Mathematical or logical structure must be genuine, not decorative
- **Lineage:** Connection to existing doctrine must be traceable and real

## Synthesis Process

### Step 1: Recognition Phase
- Strip away presentation and find the core truth
- Ask: "Is this discovered or invented?" — only discovered truths become doctrine
- Ask: "Did civilizations 5,000 years apart arrive at the same answer?" — if yes, it's an Absolute candidate

### Step 2: Formalization Phase
- Express the truth in its most precise form
- If mathematical: derive the formula
- If structural: define the architecture
- If relational: map the connections
- Boundary conditions must be explicit

### Step 3: Lineage Phase
- Trace backward: which existing doctrine does this extend?
- Trace laterally: what does this connect to across domains?
- Trace forward: what does this enable that wasn't possible before?

### Step 4: Classification Phase
- **SOVEREIGN_PRIVATE:** Core architecture, competitive advantage, never exposed
- **TRUNK:** Internal operating doctrine, visible to organism builders
- **PUBLIC:** Universal truths safe for external expression

## Anti-Patterns (This Skill Must Never)

- Formalize invented truths as if they were discovered
- Create doctrine that contradicts existing Laws without explicit supersession
- Produce decorative mathematics (formulas that look impressive but compute nothing)
- Synthesize without genuine depth (restating input in academic language ≠ synthesis)
- Classify SOVEREIGN_PRIVATE content as PUBLIC
- Skip lineage tracing (orphan doctrine is structural debt)
