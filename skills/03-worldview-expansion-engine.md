# Skill 03 — worldview-expansion-engine

## ALPHA MEDINA Architecture · Core Doctrine / Intelligence Layer

**Purpose:** Expands any concept across past/present/future, industries, organisms, markets, and expression families. This is the dimensional scaling engine — it takes a single recognized truth and reveals its full expression space.

**Governing House:** Domus Genesis + Domus Civitas (Doctrine → Civilization Expression)  
**MS Layer:** MICRO → MESO → MACRO (full shell traversal — expansion crosses all scales)  
**Law Alignment:** L06 (Expansion), L07 (Expression Families), L20 (Fractal Self-Similarity), L03 (Coherence)

The user provides ONE of the following:

| Input Type | Description | Example |

### Quality Gates

- **Genuine expansion:** Each dimension must reveal something non-obvious, not just restate the input
- **Grounded:** Past/present claims must be historically verifiable
- **Non-generic:** Industry mappings must be specific to the concept, not template-filled
- **Actionable convergence:** Convergence points must suggest concrete next moves
- **Fractal coherence:** Expansion at each scale must be self-similar in structure

## Expansion Principles

### Principle 1: Self-Similarity Across Scales
- If the concept is true, it should manifest at quantum, human, and planetary scales
- The same pattern at different scales = high-confidence truth

### Principle 2: Independent Discovery = High Confidence
- If civilizations separated by time and geography discovered the same pattern = near-Absolute status
- If only one source claims it = hypothesis, not doctrine

### Principle 3: Market Creation Over Market Entry
- The most valuable expansion reveals markets that don't yet exist
- Entering existing markets is lower-value than creating new ones

### Principle 4: Expression Families Are Complete or Incomplete
- A concept expressed at doctrine/architecture/code/product/visual/language/culture = fully expanded
- Missing expressions = opportunity for the organism

### Principle 5: Convergence Creates Compound Value
- Where two expansion dimensions intersect = higher-than-linear opportunity
- Three or more intersections = potential new Law or Absolute

## Anti-Patterns (This Skill Must Never)

- Fill dimensions with generic content (template-stuffing)
- Claim historical connections without verifiable basis
- Expand into markets without genuine differentiation argument
- Produce expression families that are just the same sentence reworded
- Miss convergence points (the highest-value output of expansion)
- Expand a concept that hasn't been genuinely recognized first (expansion of invented truths = compounded error)
