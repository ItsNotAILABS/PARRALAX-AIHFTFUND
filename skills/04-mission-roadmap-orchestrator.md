│  1. MISSION STATEMENT                               │

├─────────────────────────────────────────────────────┤
│  5. COMPOUNDING EXECUTION PATH                      │
│     - What compounds at each phase?                 │
│     - Knowledge compound: what do we learn?         │

### Roadmap Quality Gates

- **Executable:** Every phase must have concrete next-actions, not just goals
- **Gated:** No phase advances without explicit gate criteria being met
- **Honest:** Duration estimates account for real complexity, not aspirational timelines
- **Compounding:** Each phase must produce value that accelerates subsequent phases
- **Doctrine-aligned:** The roadmap structure itself reflects PARALLAX principles

## Execution Principles

### Principle 1: Gates Over Deadlines
- A phase is done when its gate criteria are met, not when a calendar date arrives
- Calendar dates are constraints, not definitions of done

### Principle 2: Compounding Over Linear
- Each phase must produce assets that accelerate future phases
- If Phase 2 doesn't benefit from Phase 1's existence, the sequencing is wrong

### Principle 3: Branch Points Are Explicit
- Every fork must be named, criteria defined, and decision authority assigned
- "We'll figure it out later" is not a valid branch strategy

### Principle 4: Risks Are Named, Not Ignored
- Every risk gets probability × impact scoring
- Mitigation is defined before the risk materializes, not after

### Principle 5: φ-Proportioned Where Applicable
- When dividing effort, time, or resources, golden ratio proportions produce natural balance
- Phase 1 : Phase 2 effort ≈ 1 : φ (if the scope naturally supports it)

## Anti-Patterns (This Skill Must Never)

- Produce aspirational timelines disguised as execution plans
- Create phases without gate criteria (ungated phases = scope creep invitation)
- Ignore dependencies (parallel execution where sequential is required)
- Produce linear plans where compounding plans are possible
- Present a single path when genuine forks exist (false certainty)
- Create roadmaps that could exist without PARALLAX doctrine (generic project management)
