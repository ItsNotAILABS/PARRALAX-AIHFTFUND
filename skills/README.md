## Architecture

Each skill is a self-contained cognitive engine with three requirements:

1. **Input** — What the user gives it (raw idea, architecture draft, project scope, bid, doctrine note, code concept)
2. **Output** — What it produces (roadmap, review, architecture spec, doctrine map, red-team audit, public report)
3. **Connectors/Tools** — What external systems it interfaces with (files, Drive, Gmail, web, GitHub, spreadsheets, PDFs)
